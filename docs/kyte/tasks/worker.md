# Worker (the brain)

The main job. Every 10 minutes in the SDR's working window it runs one cheap precheck; when there is work it takes a lock, reads Gmail (accepts and replies), works the Queue (app requests like Draft, Rescan, Map account, chat), researches and drafts DM1/DM2/DM3 and reply drafts, tags every draft, regenerates drafts that fail the copy rules, builds at most one account brief, and publishes back through the Sheet sync. Never sends anything.

| | |
|---|---|
| Schedule type | `interval` |
| Schedule config | `{"minutes": 10, "timezone": "Asia/Kolkata", "window": {"days": ["mon", "tue", "wed", "thu", "fri"], "end": "03:59", "start": "15:00"}}` |
| Timezone | Asia/Kolkata (IST) |
| Credentials it uses | Google account that owns the Sheet (gws), the worker database binding (role `ari_worker`), a browser session signed in to Apollo (people search only). |
| State at the sunset (Nov 3 2026) | paused |

## Notes for a rebuild

- It is long on purpose. Most of its rules exist because a shorter version drifted. Keep it whole.
- Placeholders: `{SELLER}` = the company you sell for, `{SELLER_SKILL}` = the skill file with plays, proof list, personas and writing rules (template in `../config/seller-skill.template.md`), `AE 1/2/3` = the AE books from `config/seller.private.json`.
- The stored exec-track values (`<EXEC> via <EXEC_ASSISTANT>`, stage `<EXEC>`, Queue actions `Send to <EXEC>` and so on) were literal strings in the old data that named a real exec. On a rebuild pick neutral values (for example route `Exec track`, stage `Exec`) and change them in the prompt, `ops.html` and `exec_track_handoff.py` together.
- `plans/copy-lab/ae-styles.md` was a private file (it named real AEs and customers). Recreate it from `../config/ae-styles.template.md`; `scripts/copy_check.py` enforces the same rules from `seller.private.json`.
