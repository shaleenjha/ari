# Daily report + exec track handoff (06:05 IST)

Emails the SDR's work inbox a short numbers-first daily report, then the exec-track handoff list. Both scripts check Gmail sent mail so nothing goes twice.

| | |
|---|---|
| Schedule type | `daily` |
| Schedule config | `{"time": "06:05", "timezone": "Asia/Kolkata"}` |
| Timezone | Asia/Kolkata (IST) |
| Credentials it uses | The owner Google account (sends from it to the work address, which was the only recipient). |
| State at the sunset (Nov 3 2026) | paused |
